LEAST 算法要点

    

      
1. 无环性约束（论文 §III）

      令 S = W∘W。迭代 S(j+1) = (b(j))-1 ∘ S(j) ∘ (b(j))T，
      其中 b(j) = (r(S(j)))α ∘ (c(S(j)))1-α。
      上界 δ(k)(W) = Σ b(k) ≥ 谱半径 ρ(S)，且 δ=0 ⟺ DAG。
      计算仅需 O(ks)，近线性于节点数（NOTEARS 的 h(W)=Tr(eS)-d 需 O(d³)）。

      
2. 梯度（论文 Lemma 3–5, Fig.2）

      用 W 的支撑掩码 M 提前屏蔽，∇Wδ = 2∇′Sδ ∘ W，全程保持稀疏。

      
3. 优化（论文 §IV, Fig.3）

      增广拉格朗日 𝓁 = (1/n)‖X−XW‖² + λ‖W‖₁ + (ρ/2)δ² + ηδ，
      内层 Adam，外层 η ← η+ρδ、ρ ← ρ·B。

      
4. 终止判据

      论文 Fig.3 用 δ ≤ ε；§V-A 为与 NOTEARS 公平对比，额外在外层末计算 h(W) 并在 h ≤ ε 时终止。
      注意 δ 只是上界（k=5 时常比 h 松 2~3 个量级），若只要求 δ ≤ ε 会让 η 无界增长、过度压缩 W 而损害结构精度 —— 本系统默认使用 §V-A 的修改版判据。
      想直接确认无环，看结果里的「谱半径 ρ(S)」卡片：它是阈值化后加权图的真实谱半径（特征值直算），≈0 即无环，比 δ 更可靠。
