# 标准贝叶斯网络基准（可直接上传到网页）

本目录的网络来自 **bnlearn Bayesian Network Repository**（Marco Scutari 维护），
是 BN 结构学习领域最权威的公开基准集：每个网络都有**真实 DAG + 条件概率表**。

官网：https://www.bnlearn.com/bnrepository/
许可：**CC BY-SA 3.0**（非原始作者，转载请注明来源与许可）

## 文件清单

| 文件 | 网络 | 节点 | 边 | 说明 |
|---|---|---|---|---|
| `asia.bif` | ASIA（Lauritzen & Spiegelhalter 1988） | 8 | 8 | 经典肺癌/结核诊断网络，最小最好演示 |
| `asia.dsc` | 同上，DSC 格式 | 8 | 8 | 用于验证 DSC 解析 |
| `asia.net` | 同上，Hugin NET 格式 | 8 | 8 | 用于验证 NET 解析 |
| `child.bif` | CHILD | 20 | 25 | 新生儿先天心脏病诊断 |
| `alarm.bif` | ALARM（Beinlich 1989） | 37 | 46 | 监护仪报警网络，中等规模标准基准 |

三种格式（BIF / DSC / NET）描述的是**同一个 ASIA 网络**，上传后应得到完全一致的
DAG 与采样分布——可用来现场验证解析器的正确性。

## 上传后会发生什么

1. 系统解析网络结构，按拓扑序对 CPT 做**前向采样**，生成 n 条样本（默认 n = 2000，可在界面调整）
2. 离散状态被编码为 `0..k-1` 的整数（例如 yes=0 / no=1）
3. **网络自身的边表被当作 ground truth**，因此结果页会显示 F1 / Precision / Recall / SHD，
   而上传普通 CSV 时这些指标显示 "—"

## 参考精度（默认参数，ε 网格 × τ 网格取最佳，n=2000）

| 网络 | F1 | 说明 |
|---|---|---|
| ASIA | ≈ 0.18 | 8 个节点、极稀疏，样本内信息量小 |
| ALARM | ≈ 0.39 | 37 节点 / 46 边 |

> **为什么偏低？** 这些网络是**离散**的，而 LEAST 假设的是**线性结构方程模型**（连续、高斯噪声）。
> 把离散类别当数值喂给线性模型本身就失配，因此这里的结果用于**横向对比**（同一网络上比较算法/参数），
> 不代表 LEAST 在连续数据上的真实水平（论文 §V-A 的 ER/SF 合成数据 F1 为 0.85–0.93）。
> 想让图更密、召回更高，可在界面把出图阈值 τ 调小（如 0.05）。
